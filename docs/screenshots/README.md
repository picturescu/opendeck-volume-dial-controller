# Screenshot guide

No screenshots are fabricated or referenced as if they already exist. Useful screenshots for a future release update would show:

- Application Volume Dial feedback.
- Dynamic Application Volume Dial beside several selector buttons.
- Output and input device dials.
- The ordered application-group property inspector.
- A Steam game using its resolved application icon.
- A complete three-button Application Volume Column.

Capture only the OpenDeck interface and device views needed to explain the feature. Remove usernames, local paths, device serial numbers, unrelated applications, notifications, and private profile information.
